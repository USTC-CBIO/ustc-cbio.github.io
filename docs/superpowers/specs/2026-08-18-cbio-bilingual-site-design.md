# CBIO Lab 全站双语切换设计

日期：2026-08-18

## 目标

在现有无构建步骤的静态站点中增加全站中英文切换能力。用户可以在顶端栏最右侧点击按钮，在中文和英文之间切换当前页面；语言选择保存到浏览器后，进入其他页面时继续使用同一语言。

本次同时修复桌面端 logo 偏上的问题：让 header 内部的 logo、导航和间距完整落在 header 高度内，移动端现有布局保持不变。

## 范围

覆盖现有 8 个页面：

- `index.html`
- `research.html`
- `team.html`
- `publications.html`
- `data-code.html`
- `news.html`
- `media.html`
- `contact.html`

切换范围包含导航、页面标题、hero 标题与说明、章节标题、正文、卡片、链接、页脚、页面 `<title>`、`<html lang>`、logo 和语言按钮的无障碍标签，以及团队页动态生成的成员信息。

不改变页面 URL、现有图片、现有导航结构和已确认的英文内容含义；不引入框架、构建工具或第三方依赖。

## 不可翻译名称规则

研究项目、方法、模型、数据集、论文和其他已命名科研对象作为不可翻译词保存。至少包括：

- `stPainter`
- `DeepSpatial`
- `DriftST`

这些名称在中文和英文界面中保持完全一致，包括大小写。研究名称周围的分类、解释和按钮文字正常翻译。例如“DeepSpatial combines ...”中的 `DeepSpatial` 不变，句子其余部分切换为对应语言。

## 推荐架构

采用共享翻译层，不复制两套页面 DOM。

### 1. 页面标记

每个页面上的可翻译文字增加稳定的 `data-i18n` key；需要翻译属性的元素增加 `data-i18n-attr` 声明，例如 logo 的 `aria-label`、语言按钮的 `aria-label` 和页面标题。页面根节点使用 `data-page` 标识页面类型，以便设置对应的 document title。

研究项目名直接保留在 HTML 文本和翻译数据中，不给它们配置翻译值，避免切换时被替换。

### 2. 共享运行时

新增 `i18n.js`，所有页面在 `script.js` 前加载。它负责：

- 保存英文/中文翻译字典；
- 从 `localStorage` 的 `cbio-language` 读取当前语言，默认英文；
- 创建并维护顶端栏右侧的语言切换按钮；
- 更新所有 `[data-i18n]` 元素、指定属性、document title 和 `<html lang>`；
- 通过 `cbio:language-change` 自定义事件通知动态模块；
- 切换后保留当前 URL、滚动位置和页面交互状态。

按钮在桌面端固定于 header 右上区域，在移动端与菜单按钮并列但不遮挡 logo；按钮显示下一步动作：英文状态显示 `中文`，中文状态显示 `EN`。

### 3. 现有脚本接入

`script.js` 保留现有菜单、首页 hero 轮播和年份逻辑，并将 hero credit 改为读取当前语言。`team.js` 为每位成员增加中文姓名、机构、身份和简介字段，气泡与内嵌 profile 根据当前语言渲染，并在收到语言事件时重新渲染但保留已选成员。

### 4. 顶部 logo 修复

桌面端将 `.site-header` 高度调整为 `190px`，使现有 `100px` logo 区域、`55px` 导航和 `25px` 间距不再溢出；`max-width:980px` 和 `max-width:640px` 的现有 header 高度分别保持 `92px` 与 `76px`。不更换 logo 资源，不改变 logo 的水平居中方式。

## 数据与文案

翻译字典按页面分组，包含公共导航、页脚、页面标题和各页面正文。中文文案使用现有英文内容的忠实翻译，不新增研究结论、论文、联系方式、职位、事件或其他事实。对于当前页面中本来就是占位内容的文字，中文版本也保持占位语气，不伪造信息。

团队页的成员姓名优先使用中文姓名字段，英文状态使用现有英文姓名；研究项目名不随语言变化。

## 可访问性与交互

- 语言按钮使用原生 `<button>`，支持键盘聚焦和 Enter/Space 操作。
- 切换按钮具有随语言变化的 `aria-label`，说明下一步可切换到的语言。
- 页面语言同步到 `<html lang>`，页面标题同步更新。
- 现有菜单按钮、团队气泡和 Escape 恢复行为保持可用。
- 切换语言不刷新页面，不弹出模态框，不改变 URL，不锁定滚动。
- `prefers-reduced-motion` 下不新增强制动画。

## 验证方案

1. 对 `script.js`、`team.js` 和 `i18n.js` 运行 `node --check`。
2. 启动静态服务器，逐页打开 8 个页面，确认页面标题、主要内容和导航无空白或运行时错误。
3. 在桌面端点击语言按钮，验证导航、正文、标题、页脚、`<html lang>` 和 document title 同步变为中文；再次点击恢复英文。
4. 在一个页面切换为中文后导航到另一个页面，验证语言状态仍为中文；刷新页面后再次验证。
5. 检查 `stPainter`、`DeepSpatial`、`DriftST` 在两种语言下完全不变。
6. 在团队页验证成员气泡、成员简介和语言切换联动；切换语言后已选成员仍保持选中。
7. 在桌面和移动视口检查语言按钮、logo、导航菜单不重叠、不出现水平溢出。
8. 检查 `git diff --check`，确认提交只包含双语功能、顶栏修复和设计说明相关文件。

## 不在本次范围内

- 不重写现有页面布局或视觉主题。
- 不改变研究项目名、logo 图片、导航 URL 或已有图片资源。
- 不增加后台内容管理、自动翻译服务或第三方语言包。
